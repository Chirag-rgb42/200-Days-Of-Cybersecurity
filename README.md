# 🛡️ 200 Days of Cybersecurity Challenge

Welcome! This is my personal repository where I am documenting my daily progress as I transition from an absolute beginner to a cybersecurity expert over the next 200 days.

---

## 🤔 What is this project?
This repository serves as a **daily learning journal and code portfolio**. Every single day for 200 days, I am:
* Writing security-focused scripts (primarily in Python).
* Learning core IT concepts (networking, operating systems, and web protocols).
* Pushing my updates to GitHub to maintain a consistent daily habit.

## 🎯 Why am I doing this?
* **To Build Strong Foundations:** To master Python automation, Linux administration, and network analysis from scratch.
* **To Practice Consistency:** To prove to myself and future employers that I can commit to a rigorous, long-term learning challenge.
* **To Document in Public:** To share my breakthroughs, code, and daily struggles on both GitHub and LinkedIn.
